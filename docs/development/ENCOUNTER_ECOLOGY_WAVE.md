## Native encounter contract

Use integer 100 Hz model ticks. A finite program contains ordered relative tick
offsets and events. Bound the queued population and horizon, validate the entire
program before appending, check arithmetic overflow, and preserve insertion order
for simultaneous events. No environment variable, object identity, event name or
program metadata is passed to cognition. Normal rendered light, sound at the
antennae and contact with moving matter enter the existing CNS afferents.

Initial event types are tones (source location, frequency, amplitude, duration),
static screen patterns (blank, uniform or grating), and forces on existing visitor
objects through the current physical-force boundary. Screen patterns are generated
in Rust. The continuous Bad Apple film remains an explicitly wall-clock source;
choosing a model-clock screen program must stop that competing screen writer.

Dispatch is an explicit beginning-of-control-tick mutation before sensory sampling,
not a side effect of opening an inspector. Repeated preparation at the same tick
cannot replay delivered events. Native snapshots contain pending events, ordering,
the dispatch clock and delivery counts. Their validation precedes restoration.
If physical delivery fails after mutation, pause; do not retry an unknown partial
delivery. Whole-life persistence uses the successor native snapshot and removes
the obsolete JavaScript queue, with an explicit new envelope format.

The browser exposes composition and queue status as a visitor tool. A greeting
is an ordinary saved program. Pausing freezes model-time intervals; checkpoint
reload preserves the pending suffix. Do not report recognition or learning from
the fact that the stimulus was delivered or neural state changed.
